# Disclosure

This repository contains design documentation only. It was derived from lessons learned while building and operating a private home dashboard, but it does not contain the original application source.

The following material is intentionally excluded:

- Addresses, names, device identifiers, entity identifiers, and camera details
- Provider account data, billing records, receipts, and notification recipients
- API tokens, connection strings, certificates, and webhook secrets
- Home Assistant configuration and automation files
- Database files, test fixtures, screenshots, logs, and deployment manifests
- Private mobile signing and push-notification configuration

Examples are generalized and do not describe a reachable deployment. The production repository should remain private.
